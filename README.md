# Khumalo Katleho — Portfolio

Personal site for Khumalo Katleho, a Computer Systems Engineering graduate working across software, computer vision, machine learning, and embedded systems.

Live: [khumalosk.vercel.app](https://khumalosk.vercel.app)

## Stack

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4
- Framer Motion, Swiper, Resend

## Scripts

```bash
npm install
npm run dev
```

- `npm run dev` — development server with Turbopack
- `npm run build` — production build
- `npm run start` — production server
- `npm run lint` — ESLint

## Content

Update copy, projects, education, and contact details in `src/data/data.ts`. Project case studies live at `/projects/[slug]`.
